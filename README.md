# fastapi-tableau-webhooks

Welcome to the **FastAPI Tableau Webhooks** project! 🚀

## About This Project

This repository is all about making Tableau webhook integrations a breeze. Whether you're automating workflows, sending notifications, or just geeking out over Tableau's capabilities, this project has you covered. Built with the power of **FastAPI**, it ensures your webhook handling is fast, reliable, and scalable.

- **Email Notifications**: Automated email alerts for key events.
- **Customizable**: Easily adapt the code to fit your unique needs.
- **FastAPI-Powered**: Enjoy the speed and simplicity of FastAPI.

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/kjmassey/fastapi-tableau-webhooks.git
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Update and rename *.rename_me_env* in the root with your values
4. Run the server:
   ```bash
   fastapi dev
   ```
5. Test the endpoints using your favorite API client using the included Postman collection/environment -- be sure to update the environment values.
